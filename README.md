# Sales Performance Analysis

## Project Overview
This project analyzes sales data using Microsoft Power BI to understand sales performance, profitability, and regional trends.

## Tools Used
- Microsoft Excel
- Microsoft Power BI

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Features
- Sales by Category
- Sales by Region
- Profit by Sub-Category
- Monthly Sales Analysis
- Sales by Region and Category
- Interactive filters for Region, Category, Sub-Category, and Month
- Date Range Filter

## Project Objectives
- Analyze overall sales and profit.
- Identify top-performing regions and categories.
- Understand monthly sales trends.
- Support better business decisions through data visualization.
